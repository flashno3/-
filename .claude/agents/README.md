# 증권사 보고서 작성 에이전트 팀

| 에이전트 | 역할 | 도구 |
|---|---|---|
| `securities-ceo` | 전략·리스크·최종 결정 | 읽기 전용 |
| `securities-cfo` | 재무·자본적정성·숫자 검증 | 읽기 전용 |
| `mgmt-planning-head` | 보고서 총괄·검수 | 읽기 전용 |
| `mgmt-planning-staff` | 자료 집계·계산·초안 | 읽기 + Bash |

## 진행 순서 (메인 에이전트가 중계)
1. 부장이 구조를 잡고 실무자에게 지시
2. 실무자가 초안 작성 (출처·계산 내역 포함)
3. 부장 검수 → 보완
4. CFO 숫자 검증
5. CEO 전략·리스크 검토
6. 지적 사항을 실무자가 수정 (이력 기록), 필요 시 3~5 반복 (최대 2~3라운드)
7. 사용자 승인 후 확정

서브에이전트끼리 직접 대화하지 않고, 메인 에이전트가 산출물을 전달합니다.

## 공통 원칙
- 자료에 없는 수치는 만들지 않고 `[근거 없음]` / `[확인 필요: ...]` 표시
- 모든 수치에 출처, 계산에는 계산식과 입력값
- 수정은 덮어쓰지 않고 변경 전/후와 사유를 남김
