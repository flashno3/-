# KBO 감독 모드

구단을 골라 감독으로 운영하는 게임. 서버 없이 `game/index.html` 한 파일로 실행된다(브라우저 저장소에 자동 저장).

## 빌드
```
python3 build_game_data.py   # 선수 데이터: 3시즌 블렌딩 능력치 + 수비·포지션 → game/src/gamedata.json
python3 build_game.py        # game/index.html (단일 파일), game/artifact.html (게시용 본문)
game/run_tests.sh            # 전체 검증
```

## 구성
- `web/src/engine.js` : 경기 엔진(파이썬 engine2.py 와 결과가 같은 JS 포팅). `LiveGame` 이 타석 단위 진행과 감독 개입(투수 교체·대타·고의사구·번트·도루)을 제공
- `game/src/league.js` : 선수 평가(OVR·연봉·시장가치), 로스터/라인업/로테이션/불펜, 일정, 하루 진행, 내 경기 준비·종료, 포스트시즌 상태기계
- `game/src/offseason.js` : 성장·노화·은퇴, 계약 만료·재계약, 신인 드래프트, FA 시장, 트레이드, 새 시즌
- `game/src/app.js` : 화면(팀 선택, 대시보드, 로스터, 라인업, 투수진, 일정, 순위·기록, 이적시장, 오프시즌, 경기)

## 규칙
- 정규시즌 144경기(매일 5경기, 월요일 휴식), 5위까지 포스트시즌: 와일드카드(4위 1승 어드밴티지) → 준PO → PO → KS
- 1군 28명, 총 보유 44~70명, 연봉 총액 상한(초기 평균 연봉 × 1.25)
- 내 라인업의 선수가 낯선 포지션에 서면 수비 범위·실책 페널티. 매 경기 선발의 5%는 컨디션 난조로 결장(후보가 대신)
- 불펜: 마무리(세이브 상황)·셋업(7~8회 박빙)·롱릴리프(큰 점수 차)·중간. 투구 이닝에 따라 피로가 쌓이고 3일 연투하면 휴식 필요. 선발은 4일 이상 휴식
- 오프시즌 순서: 성장·노화·은퇴 → 재계약 → 드래프트(성적 역순, 10라운드) → FA → 새 시즌. 트레이드는 시즌 중 110일차까지와 오프시즌
- AI 구단은 선수 출전을 기록 기반 확률로 정하고(기존 시뮬레이터와 같은 방식), 재계약·FA·드래프트·트레이드 응답은 시장가치 기준
- 리그 전체 실력 수준은 매 시즌 기준선에 맞춰 보정(능력치 인플레이션 방지). 팀 간 격차는 그대로 유지

## 가정(데이터에 없는 부분)
- 계약·연봉은 데이터에 없어 능력치 기반으로 생성한 값이다
- 신인 능력치·잠재력, 성장 곡선, 은퇴 확률은 일반적인 값으로 설정한 것
- 부상은 구현하지 않았고, 선발 결장 5%와 투수 피로만 있다
- 외국인 선수 쿼터는 반영하지 않았다
