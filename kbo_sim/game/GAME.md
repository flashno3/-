# KBO 감독 모드

구단을 골라 감독으로 운영하는 게임. 서버 없이 `game/index.html` 한 파일로 실행된다(브라우저 저장소에 자동 저장).

## 빌드
```
python3 build_game_data.py   # 선수 데이터: 3시즌 블렌딩 능력치 + 수비·포지션 → game/src/gamedata.json
python3 build_game.py        # game/index.html (단일 파일), game/artifact.html (게시용 본문)
game/run_tests.sh            # 전체 검증
```

## 구성
- `web/src/engine.js` : 경기 엔진(파이썬 engine2.py 와 결과가 같은 JS 포팅). `LiveGame` 이 타석 단위 진행과 감독 개입(투수 교체·대타·고의사구·번트·도루)을 제공
- `game/src/league.js` : 선수 평가(OVR·연봉·시장가치), 로스터/라인업/로테이션/불펜, 일정, 하루 진행, 내 경기 준비·종료, 포스트시즌 상태기계
- `game/src/offseason.js` : 성장·노화·은퇴, 계약 만료·재계약, 신인 드래프트, FA 시장, 트레이드, 새 시즌
- `game/src/app.js` : 화면(팀 선택, 대시보드, 로스터, 라인업, 투수진, 일정, 순위·기록, 이적시장, 오프시즌, 경기)

## 규칙
- 정규시즌 144경기(매일 5경기, 월요일 휴식), 5위까지 포스트시즌: 와일드카드(4위 1승 어드밴티지) → 준PO → PO → KS
- 1군 28명, 총 보유 44~70명, 연봉 총액 상한(초기 평균 연봉 × 1.25)
- 포지션 숙련도 3단계: 주포지션 / 소화 가능(해당 포지션 선발 15경기 이상) / 부적합. 수비 출전이 거의 없는 선수(예: 최형우 좌익수 6경기)는 지명타자형으로 분류. 부적합 포지션에 서면 수비 범위가 크게 줄고 실책이 늘어 안타를 더 맞는다(포수·유격수·중견수·2루수·3루수는 특히 크다). 선발로 15경기를 뛰면 새 포지션에 적응해 '소화 가능'이 된다. 자동 라인업은 9자리를 한 번에 최적 배정(동적계획법)
-  매 경기 선발의 5%는 컨디션 난조로 결장(후보가 대신)
- 불펜: 마무리(세이브 상황)·셋업(7~8회 박빙)·롱릴리프(큰 점수 차)·중간. 투구 이닝에 따라 피로가 쌓이고 3일 연투하면 휴식 필요. 선발은 4일 이상 휴식
- 오프시즌 순서: 성장·노화·은퇴 → 재계약 → 드래프트(성적 역순, 10라운드) → FA → 새 시즌. 트레이드는 시즌 중 110일차까지와 오프시즌
- AI 구단은 선수 출전을 기록 기반 확률로 정하고(기존 시뮬레이터와 같은 방식), 재계약·FA·드래프트·트레이드 응답은 시장가치 기준
- 리그 전체 실력 수준은 매 시즌 기준선에 맞춰 보정(능력치 인플레이션 방지). 팀 간 격차는 그대로 유지

## 가정(데이터에 없는 부분)
- 계약·연봉은 데이터에 없어 능력치 기반으로 생성한 값이다
- 신인 능력치·잠재력, 성장 곡선, 은퇴 확률은 일반적인 값으로 설정한 것
- 부상은 구현하지 않았고, 선발 결장 5%와 투수 피로만 있다
- 외국인 선수 쿼터는 반영하지 않았다

## 경기 중 개입 (직접 지휘)
- 교체: 투수 교체, 대타, 대주자(타순·수비 위치 이어받음), 수비 교체(벤치 선수로 교체 / 다른 야수와 수비 위치 맞바꾸기)
- 작전: 희생번트, 도루, 고의사구, 히트앤드런, 견제구, 마운드 방문
- 공격 접근(내가 공격할 때): 컨택(삼진·홈런↓, 3루 주자 시 득점 쉬움) / 장타(홈런·삼진↑) / 신중(볼넷↑ 홈런↓)
- 투구 접근(내가 수비할 때): 공격적 승부(볼넷↓ 홈런·피안타↑) / 신중한 승부(홈런↓ 볼넷↑) / 삼진 유도(삼진↑ 볼넷·홈런↑)
- 전진 수비: 3루 주자·2사 미만에서 쉬운 득점을 줄이는 대신 안타 확률↑
- 투수 체력: 선발은 평균 이닝 기준(약 25명), 구원은 약 9명이 한계. 넘기면 볼넷·피홈런·피안타가 늘고 삼진이 줄어든다(한계 +6명이면 타석당 실점 약 +22%)
- 코치 조언: 투수 체력, 고의사구, 전진 수비, 컨택/장타 접근, 대타·대주자·번트 후보를 상황에 맞춰 제안
- 작전 효과는 평균적으로는 실점 ±1.5% 이내로 균형을 맞췄고(표본 4만 경기), 상황에 따라 유불리가 갈린다

## 화면
- 모바일: 하단 고정 진행 바(날짜·성적·진행 버튼), 진행 직후 결과 시트(기간 성적·순위 변화·경기별 점수), 경기 화면은 고정 점수판 + 최근 플레이 배너 + 하단 고정 조작부
- 팀 엠블럼: 공식 로고가 아니라 팀 색과 상징 도형(곰 귀, 호랑이 줄무늬, 사자 갈기 등)으로 만든 자체 엠블럼. 내 팀 색이 메뉴·바 테마에 반영된다

## 히트앤드런·투수 견제
- 히트앤드런(무사·1사 1루): 1루 주자가 스타트하고 타자는 맞히려 한다. 삼진·볼넷·병살이 줄고 주자가 한 베이스 더 가기 쉽다. 대신 타구가 약해지고(컨택이 약한 타자일수록 더), 헛스윙 삼진이면 도루 실패 위험이 있다. 주자 발이 빠를수록 진루·득점 확률이 더 오른다
  - 측정(무사 1루, 표본 12만): 컨택 좋은 타자 + 빠른 주자 +0.06점, 평균 +0.01~+0.04, 삼진 많은 타자 + 느린 주자 -0.01점
- 견제구: 약 3~11% 확률로 주자를 잡고(느린 주자일수록 높음), 시도할수록 효과가 줄며 가끔 악송구가 나온다. 한 이닝에 3번째 견제는 보크(주자 전원 진루). 던질 때마다 투수 체력이 조금 닳는다
- 주자 견제 지시(홀드): 1루 주자가 있을 때 도루 시도를 크게 줄이고(도루사 8.8% → 5.0%) 성공률도 낮추지만 투구에 약간 부담(볼넷 +4%)

## 로고
- 구단 로고는 사용자가 제공한 이미지(10개 구단 시트)를 잘라 WebP 데이터로 포함(game/src/logos.json). 모든 화면에서 사용

## 마운드 방문
- 경기당 3번, 한 이닝에 두 번은 불가. 투수 체력(상대 타자 수)을 2명분 회복하고 다음 3타자 동안 볼넷·피홈런이 줄고 삼진이 늘어난다(투수를 바꾸면 즉시 해제)
- 코치 조언: 최근 3타자 중 2명 이상 출루를 허용했을 때 제안

## 좌우 매치업(플래툰)
- 투타 정보는 데이터에 없어서 처음에는 비어 있고, 정보가 없는 선수는 좌우 상성 없이 중립이다. 저장·설정 화면에서 KBO 선수 등록 현황 표를 붙여넣거나 `이름,팀,우투좌타` 줄로 입력하면 적용된다. 입력 안 된 선수 목록을 양식으로 복사할 수 있다
- 효과: 좌타자는 좌투수에게 홈런 -12%·삼진 +5% 등으로 불리하고 우투수에게 약간 유리, 우타자는 좌투수에게 소폭 유리·우투수에게 소폭 불리, 양타자는 항상 반대 손(미세). 타자 유형별 평균 노출(우투수 72%)을 빼서 리그 평균은 변하지 않는다(14시즌 평균 득점 차 +0.02, 표준오차 0.02)
- 대타 후보는 좌우 상성(유리/보통/불리)과 추천 순서로 보이고, 코치 조언이 불리한 상성일 때 대타를 제안한다. 가상 신인은 투타가 무작위로 생성된다

## 수비 포지션 점검 내역
- 라인업에서 선수를 바꾸면 수비 위치를 자동으로 다시 배정한다(예: 심우준 자리에 최재훈을 넣어도 포수는 포수로). 직접 바꾼 위치로 인한 부적합은 경고와 함께 후보 교체를 제안한다([교체 적용] 한 번으로 수정)
- 경험이 적은 포지션(선발 1~14경기)은 경험에 비례해 페널티가 줄어든다. 컨디션 난조 대체 선수도 같은 기준으로 고른다
- 최적 배정은 9자리를 한 번에 풀고(포수는 어깨도 반영), AI 팀은 오프시즌에 포수·유격수·중견수·2루수·3루수 주포지션 선수가 2명 미만이면 보강한다

## 2군 시스템 (1단계)
실제 2군(퓨처스) 선수 데이터는 아직 없으므로, 현재 리그의 선수 풀을 1군 28명과 2군(나머지)으로 나누어 운영한다.
- **엔트리**: 1군 28명(타자 최소 10, 투수 최소 8). 2군으로 내리면 시즌 중에는 **10경기일 동안 재등록 불가**(프리시즌·시즌 종료 후에는 자유, 새 시즌에 초기화). 트레이드·드래프트·FA로 온 선수는 2군에서 시작.
- **AI 팀**: 시즌 시작·트레이드 후 자동 편성(주전 9 + 백업 5(포수 2명 이상) + 선발 5 + 불펜 9). 시즌 중에는 바꾸지 않는다.
- **2군 경기**: 매일 1군과 같은 날짜에 144경기(별도 일정·별도 시드)를 같은 엔진으로 자동 진행. 2군 팀 라인업·로테이션은 2군 선수 중 자동 편성(인원이 모자라면 1군 후보 중 가치가 낮은 선수로 보충). 2군 기록·순위·최근 10경기 성적(`S.stats2/rec2/recent`)을 저장한다.
- **성장**: 26세 이하 선수는 시즌 출전량(1군 기록 + 0.8×2군 기록, 풀타임 기준 타자 450타석·선발 550/불펜 200타자)에 따라 성장폭이 최대 45%까지 줄어든다. 27세 이상은 영향 없음. 리그 평균은 매 시즌 기준선으로 보정된다.
- **화면**: 상단 메뉴 `2군` — 콜업 추천(능력치 + 최근 10경기 성적 참고, 1군 비주전 최저 OVR와 맞교체), 2군 선수·1군 엔트리 표, 2군 순위.
- **아직 없는 것(2단계)**: 실제 퓨처스 선수 데이터, 좌우·포지션 실데이터, 부상·군복무.
- 검증: `node game/tests_farm.js` (규칙·잠금, 2군 144경기, 1군 득점환경 유지, 저장 호환).

## 연봉·샐러리캡 (경쟁균형세, KBO 규정)
- **산정**: 구단별 연봉 상위 40명 합계(신인·외국인 제외). 상한 2027년 151.1709억, 2028년 158.7294억(+5%/년), 이후 동결 가정. 하한은 2027년부터 60.6538억(2028년 +5%).
- **정산**(시즌 종료 시): 상한 초과 1회 초과분의 30%, 2회 연속 50%, 3회 연속 100%를 야구발전기금으로 납부하고, 3회 연속이면 다음 드래프트 1라운드 지명이 9단계 하락. 하한 미달도 같은 비율(30/50/100%)로 납부. 상한은 **하드캡이 아니라** 초과가 허용되며 위 제재만 받는다(화면 헤더·FA·순위 화면에 미리보기 표시).
- **AI 구단**: 상한을 넘기지 않게 영입·트레이드하고, 하한에 못 미치면 FA를 영입해 맞춘다.
- **연봉 규모(구버전 설명, 아래 '2026 실제 연봉' 참조)**: 실제 선수 연봉 데이터가 없어, 모델 연봉(최저 0.3억 + 가치분)을 2025년 구단 평균 상위 40명 합계(111.05억, KBO 발표 평균)에 맞춰 환산했다. 개별 선수 연봉은 추정치.
- **미반영**: 프랜차이즈 예외 선수(7시즌 이상 소속 1명, 연봉 50% 제외; 재적 연수 데이터 없음), 외국인 구분(데이터에 없어 이름이 한글이 아닌 선수만 제외), 다년계약 평균 산정, 옵션·계약금.
- 출처: KBO 2025.9 이사회 개정(상한 5% 인상, 제재 완화, 하한 도입) 보도 기준. 세부 조항은 KBO 공식 문서로 확인 권장. 검증: `node game/tests_cbt.js`.

## 2군 선수 데이터 (2단계, 타자)
- **입력 자료**(`game/data/`): 퓨처스 선수등록 명단 `futures_roster_2026.txt`(투타·생년월일), 2026 퓨처스 타자 기록 `futures_bat_2026.txt`(playerId 포함, 시즌 도중 누적). 입력 검증: AVG·SLG 재계산 일치, H≥장타, PA≥AB+BB+HBP, playerId 중복 없음(`tests_futures.js`).
- **게임 반영**: 기록 행 448개 중 1군 선수와 이름+소속팀이 같은 223명은 기존 1군 능력치를 유지하고, 나머지 175명은 새 2군 타자로 추가. 상무·울산 소속 50명은 원소속 구단을 몰라 넣지 않았다. 최대 보유 인원을 70→120명으로 늘렸다.
- **능력치 환산**: 퓨처스 비율(삼진·볼넷·사구·홈런·BABIP·장타비율·도루시도)을 1군과 같은 표본 크기로 퓨처스 리그 평균 쪽으로 수축한 뒤, **1군 레이팅이 있는 겹치는 선수 157명(PA≥40)으로 회귀**해 1군 척도로 변환(PA 가중). 기록만으로는 예측력이 낮아(상관 0.15~0.4) 신규 선수의 능력치는 평균 쪽으로 모인다. 평균 OVR은 1군 주전보다 약 10 낮다.
- **추정값(화면에 칩 표시)**: 세부 포지션(내야 1B/2B/3B/SS, 외야 LF/CF/RF는 선수 ID 해시로 임의 배정, 같은 그룹의 다른 포지션은 8경기 경험으로 부분 숙련), 수비 능력(평균), 명단에 없는 선수의 나이(24세), 포수 도루저지. 도루 시도는 도루성공률 74.5% 가정으로 환산.
- **투수(2026 퓨처스 투수 기록 447행, ERA 재계산 전부 일치)**: 1군 투수와 이름+소속이 같은 218명은 기존 능력치 유지, 188명을 새 2군 투수로 추가(상무·울산 41명 제외). 타자 상대 수(BF)는 아웃+피안타+볼넷+사구로 추정하고, 삼진·볼넷·사구·홈런·BABIP을 같은 방식(수축 + 겹치는 1군 투수 147명 회귀)으로 환산. 홈런·BABIP은 예측력이 없어(상관 ≈0) 평균값으로 둔다. 선발 기록이 없어 **경기당 이닝 ≥3.5 & 25이닝 이상이면 선발로 추정**(15명), 체력은 ratings.py 공식 적용(`보직 추정` 칩).
- **한계**: 선택 편향 — 환산식을 1군 경험이 있는 선수로 맞췄기 때문에 1군에 못 올라온 선수의 실력은 다소 높게 나올 수 있다. 투수 기록은 아직 없음.

## 드래프트 신인 잠재력 (확률적 정점)
- 드래프트 후보는 가상 선수. 각 신인은 숨은 **정점 OVR(peak)**을 확률로 뽑는다: 슈퍼스타급(68~80) 2.5%, 확실한 주전급(57~68) 12%, 준주전급(48~57) 25%, 후보급(38~48) 38%, 육성급(28~38) 22.5%.
- 현재 능력치는 정점에서 (27−나이)×2+4를 뺀 값 ± 7로 정렬해, 지금 못해 보여도 크는 선수·지금 좋아 보여도 정체하는 선수가 모두 나온다.
- **스카우트 평가(`scout.ceil`) = 정점 + 오차(σ=16)**, 지명은 `0.35×현재 + 0.65×상한 평가`로 한다. 그래서 순번이 높을수록 정점이 높을 확률은 크지만(상관 0.54, 스카우트 상위 10% 중 주전급 이상 61%, 슈퍼스타 15%) 확정은 아니고, 중하위 지명에서 대성하는 경우도 나온다(30~60% 구간 주전급 이상 8%).
- 성장: 27세까지 해마다 정점과의 격차를 (남은 연수)로 나눠 좁히고, 정점 자체도 해마다 ±1.8 흔들리며 5%는 ±5 급변(대성장·정체). 출전하지 못하면 성장이 더딘 규칙은 그대로. 27세 평균 OVR: 슈퍼스타급 74 → 주전급 63 → 준주전 54 → 후보 44 → 육성 34(각 등급 10~90% 범위가 겹쳐 경계가 열려 있음).
- 스카우트 평가는 시즌마다 정점 쪽으로 정확해지고(선수 상세 `상한 평가` 칩), 드래프트 화면에는 등급명(슈퍼스타급/확실한 주전급/준주전급/후보급/육성급)이 추정치로 표시된다. 기존 선수(나이로 잠재력 부여)는 기존 방식 유지.
