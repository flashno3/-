# 검증 불가(⚠) 가정값 목록 — 3단계

> 데이터 정합성 원칙: **실측·규약으로 확인된 값**과 **설계 가정값**을 분리해 관리한다.
> 이 문서는 GAME.md 전체의 ⚠ 표시(55곳)를 영역별로 모은 것이다. 각 항목에 *유지 / 검증 요청 / 제거 후보* 권고를 붙였다.
> 코드는 건드리지 않았다 — 권고는 사용자 판단용. (기술 프로젝트는 사용자 요청대로 **유지**, 최종 사용 후 재결정)

범례: **영향** = 결과(순위·재정·성장)에 미치는 크기. 상=시즌 결과가 눈에 띄게 달라짐 / 중=특정 화면·선수군 / 하=표시·편의.
