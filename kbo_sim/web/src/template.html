KBO 시즌 시뮬레이터

10개 구단 144경기 정규시즌, 이어서 포스트시즌

엔진은 파이썬 시뮬레이터(engine2.py)를 그대로 옮긴 것으로, 같은 시드와 같은 모드의 정규시즌 결과가 파이썬과 완전히 같습니다. 포스트시즌: 와일드카드 결정전(4위 1승 안고 시작, 최대 2경기) → 준플레이오프(5전 3선승) → 플레이오프(5전 3선승) → 한국시리즈(7전 4선승). 연장은 15회까지, 무승부는 승패 없이 재경기합니다. 포스트시즌 가정: 선발은 시즌 선발 이닝 상위 4명 로테이션, 주전은 모든 경기 출전, 홈 어드밴티지는 구장 효과만 반영합니다.
